Erratum (2026-07-20; updated 2026-07-21)

The submitted thesis (Thesis_UvA_Kaleb_Mazurek.pdf, September 2023) calls the prominence classifier an SVM with count vectorization. That is a naming error. The model actually deployed was Multinomial Naive Bayes with TF-IDF and SMOTE, as its own technical appendix documents; I confirmed the model family in 2026 from the original code and the saved model. The appendix reports F1 about 0.73 for that model on the 825-row labelled selection set. That is a model-selection metric, not a measured accuracy on the full deployed set. The results are unaffected: every deployed label came from that Naive Bayes model. The "F1 0.79 / 0.65, accuracy about 81%" numbers in the text are from a discarded SVM prototype, not the deployed model.

Added 2026-07-21. A second point, about the analysis rather than the classifier. The thesis reports its headline model as a mixed-effects logistic regression: a binary prominence outcome, crossed random effects for organization and policy area, results given as odds ratios. That is correct as published. The negative-binomial count models in the project files were exploratory and were not the reported model. I have since rebuilt that regression from the archived data as a runnable reproduction, included in this repository, and it recovers the published model's structure and substantive conclusions. It is not a numeric match to the odds ratios printed in the thesis: the re-analysis runs on a different sample and salience structure, so the salience odds ratios differ from the published ones.

The submitted PDF is left unchanged as the record; this note is the correction.
